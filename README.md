# Retail Analytics Project

## Overview
This project explores retail transaction data to identify sales trends, category performance, and potential profitability issues. This repository currently contains the **initial prototype**; development is ongoing.

## Datasets
The project uses five datasets:
- Transactions
- Customers
- Products
- Inventory
- Campaigns

## Work Completed
- Loaded the five datasets into pandas.
- Performed initial data cleaning and duplicate checks.
- Checked data quality and relationships between datasets.
- Created a transaction-level analysis dataset.
- Calculated estimated sales, costs, and margins.
- Explored monthly sales, category performance, and sales channels.
- Started investigating negative-margin transactions.

## Preliminary Findings
- The transaction-level dataset contains 18,000 rows and 39 columns.
- Estimated sales across the current dataset are approximately 9.39 million (currency and transaction-status treatment still to be validated).
- Negative-margin transactions require further investigation, including pricing, costs, and discounts.

## Planned Work
- Validate financial calculations and transaction statuses.
- Investigate negative-margin records in greater detail.
- Develop clear visualizations and an interactive dashboard.
- Present actionable business recommendations.

## Current Status
**Initial prototype — work in progress.** The current focus is data preparation and exploratory analysis. The final prototype will build on these results.
