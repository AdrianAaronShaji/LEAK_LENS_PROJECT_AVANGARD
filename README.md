LEAKLENS:

An end-to-end retail analytics project that transforms sales, customer, product, inventory, and campaign data into actionable business insights using data analysis, interactive visualizations, and machine learning.

PROJECT OVERVIEW

1. dashboard.ipynb
Performs data cleaning, quality checks, exploratory data analysis, sales and profitability analysis, inventory monitoring, and generates an interactive HTML dashboard.

2. model.ipynb
Trains a Random Forest Regression model to predict daily product demand and compares its performance against a seven-day moving-average baseline.

KEY FEATURES

- Data cleaning, validation, and integration
- Sales trends, category performance, and channel analysis
- Profitability, discounts, and negative-margin analysis
- Inventory risk monitoring and business insights
- Interactive charts and an HTML dashboard
- Demand prediction using historical sales and calendar features
- Model evaluation using Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE)
- Feature importance analysis and prediction exports

TECHNOLOGIES USED

Python, Pandas, NumPy, Matplotlib, Plotly, Scikit-learn, Joblib, and Jupyter Notebook.

PROJECT OBJECTIVE

Demonstrate how data analytics and machine learning can support data-driven retail decisions, improve business performance visibility, and evaluate product-demand prediction accuracy.

NOTE

The current model evaluates predictions on historical test data and does not yet generate forecasts beyond the end of the dataset.
